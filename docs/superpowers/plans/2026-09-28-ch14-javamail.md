# Chapter 14 JavaMail & Database Hosting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng hoàn chỉnh bài tập Chapter 14 JavaMail theo chuẩn sách Java Murach (Slide 21-28 của Chapter 14 slides.pptx), hỗ trợ lưu trữ vào MySQL Database và gửi email thực tế qua Gmail SMTP, sẵn sàng cho việc hosting cục bộ và đám mây.

**Architecture:** 
- Mô hình MVC chuẩn Java Servlets & JSP (Jakarta EE 11 / Tomcat 10/11).
- Controller: `EmailListServlet` quản lý điều hướng và luồng nghiệp vụ.
- Model & DAO: `User` JavaBean và `UserDB` thực thi ghi dữ liệu vào MySQL qua `ConnectionPool` (hỗ trợ cả JNDI lẫn biến môi trường khi hosting).

- View: `index.jsp`, `thanks.jsp`, các file includes và file định dạng `main.css`.

**Tech Stack:** Java 17, Jakarta EE 11, Jakarta Mail (Angus Mail 2.0.3), MySQL Connector/J 8.3.0, JSTL 3.0, Apache Tomcat 10/11, Maven.

- [ ] **Step 1: Viết `murach.util.MailUtilLocal.java`**
Tuân thủ tuyệt đối cấu trúc Slide 21-22 của `Chapter 14 slides.pptx`:
```java
package murach.util;
import java.util.Properties;
import jakarta.mail.*;
import jakarta.mail.internet.*;

public class MailUtilLocal {
    public static void sendMail(String to, String from,
            String subject, String body, boolean bodyIsHTML)
            throws MessagingException {
        // 1 - get a mail session
        Properties props = new Properties();
        props.put("mail.transport.protocol", "smtp");
        props.put("mail.smtp.host", "localhost");
        props.put("mail.smtp.port", "25");

        Session session = Session.getDefaultInstance(props);
        session.setDebug(true);

        // 2 - create a message
        Message message = new MimeMessage(session);
        message.setSubject(subject);
        if (bodyIsHTML) {
            message.setContent(body, "text/html; charset=UTF-8");
        } else {
            message.setText(body);
        }

        // 3 - address the message
        Address fromAddress = new InternetAddress(from);
        Address toAddress = new InternetAddress(to);
        message.setFrom(fromAddress);
        message.setRecipient(Message.RecipientType.TO, toAddress);

        // 4 - send the message
        Transport.send(message);
    }
}
```

- [ ] **Step 2: Viết `murach.util.MailUtilGmail.java`**
Kế thừa cấu trúc Slide 27-28, nâng cấp bảo mật TLS hiện đại (port 587 hoặc 465) và hỗ trợ đọc App Password qua biến môi trường / tham số:
```java
package murach.util;
import java.util.Properties;
import jakarta.mail.*;
import jakarta.mail.internet.*;

public class MailUtilGmail {
    public static void sendMail(String to, String from,
            String subject, String body, boolean bodyIsHTML)
            throws MessagingException {
        // Lấy thông tin tài khoản và mật khẩu ứng dụng từ biến môi trường hoặc cấu hình
        String username = System.getenv("GMAIL_USERNAME");
        if (username == null || username.isBlank()) {
            username = from;
        }
        String password = System.getenv("GMAIL_APP_PASSWORD");
        if (password == null || password.isBlank()) {
            password = System.getProperty("mail.gmail.password", "");
        }

        Properties props = new Properties();
        props.put("mail.transport.protocol", "smtp");
        props.put("mail.smtp.host", "smtp.gmail.com");
        props.put("mail.smtp.port", "587");
        props.put("mail.smtp.auth", "true");
        props.put("mail.smtp.starttls.enable", "true");
        props.put("mail.smtp.ssl.trust", "smtp.gmail.com");

        final String authUser = username;
        final String authPass = password;

        Session session = Session.getInstance(props, new Authenticator() {
            @Override
            protected PasswordAuthentication getPasswordAuthentication() {
                return new PasswordAuthentication(authUser, authPass);
            }
        });
        session.setDebug(true);

        Message message = new MimeMessage(session);
        message.setSubject(subject);
        if (bodyIsHTML) {
            message.setContent(body, "text/html; charset=UTF-8");
        } else {
            message.setText(body);
        }

        Address fromAddress = new InternetAddress(from);
        Address toAddress = new InternetAddress(to);
        message.setFrom(fromAddress);
        message.setRecipient(Message.RecipientType.TO, toAddress);

        Transport.send(message);
    }
}
```
